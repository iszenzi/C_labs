# Лабораторная работа №6 (Скрипт на Bash)

## Цель работы
Реализовать скрипт на Bash, который удаляет все файлы с указанным суффиксом при наличие файлов с теми же именами, но с другим заданным суффиксом. (Вариант 7)

## Идея, метод, алгоритм решения задачи
Скрипт должен принимать 2 аргумента, в противном случае завершает работу через `exit 1`. Первый аргумент - суффикс файлов, которые необходимо удалить при наличие файла с тем же названием, но с суфиксом как у второго аргумента. Цикл for пробегается по всем файлам с нужным суффиксом (первый аргумент), на каждой итерации вычисляем имя файла без суффикса (первый аргумент) и проверяем есть ли файл с тем же именем но с суфиксом (второй аргумент): если есть - удаляем исходный файл, иначе оставляем файл в директории.


## Пример работы и запуск
Создадим тестовые файлы (не забудьте перейти в нужный директорий `cd 6_lab`)
```bash
touch text.txt text.bak notes.txt readme.bak photo.png photo.jpg photo1.png
```
Посмотрим на список всех файлов
```bash
ls -1
```
Вывод кода:
```
cleanup.sh
notes.txt
photo.jpg
photo.png
photo1.png
readme.bak
REPORT.md
text.bak
text.txt
```

Удалим файлы .txt, если у них есть копия в формате .bak
```bash
bash cleanup.sh .txt .bak
```
Вывод кода:
```
Запуск очистки
Цель для удаления: *.txt
Триггер наличия:   *.bak
-----------------------------------
Пропуск: для файла 'notes.txt' пара 'notes.bak' не найдена.
Найдена пара: существует 'text.bak'. Удаляю 'text.txt'...
-----------------------------------
Работа успешно завершена
```

Удалим файлы .png, если у них есть копия в формате .jpg
```bash
bash cleanup.sh .png .jpg
```
Вывод кода:
```
Запуск очистки
Цель для удаления: *.png
Триггер наличия:   *.jpg
-----------------------------------
Найдена пара: существует 'photo.jpg'. Удаляю 'photo.png'...
Пропуск: для файла 'photo1.png' пара 'photo1.jpg' не найдена.
-----------------------------------
Работа успешно завершена
```
Как мы видим файл `text.txt` и `photo.png` удалились, другие файлы, у которых нет копий нужного формата остались
```bash
ls -1
```
Вывод кода:
```
cleanup.sh
notes.txt
photo.jpg
photo1.png
readme.bak
REPORT.md
text.bak
```
