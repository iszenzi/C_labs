# Лабораторная работа №5 (Остовные деревья графов)

## Цель работы
Реализовать алгоритм на графах для нахождения минимального остовного дерева (МОД).
В качестве представления графа используется матрица инцидентности, а реализуемый алгоритм — Прима. 
Программа должна обеспечивать возможность чтения графа из файла и сохранения результата обхода/построения МОД обратно в файл. Также необходимо написание модульных тестов и замеров производительности.

## Идея, метод, алгоритм решения задачи
- **Матрица инцидентности**: это матрица размером $V \times E$, где $V$ — количество вершин, а $E$ — количество рёбер. В нашей реализации: наличие связи 1 означает, что вершина инцидентна ребру.
- **Алгоритм Прима**: Жадный алгоритм, находящий минимальное остовное дерево. 
  - Инициализируем массив visited, помечаем стартовую (нулевую) вершину.
  - Пока количество добавленных в МОД ребер меньше $V - 1$, на каждой итерации:
    1. Ищем ребро с наименьшим весом, которое соединяет связную (посещённую) вершину и не посещённую вершину, обходя матрицу инцидентности по столбцам.
    2. Добавляем найденное ребро в новый граф МОД.
    3. Помечаем новую вершину как посещенную.
  - Если связных ребер нет (граф несвязный), выполнение прерывается.

## Сценарий выполнения работы
1. Описаны структуры для работы с графом (`graph.h` / `graph.c`)
2. Написаны функции ввода-вывода `load_graph_from_file` и `save_graph_to_file`
3. Реализована функция `prim_mst(Graph* g)`, которая строит новое минимальное остовное дерево из поданного на вход.
4. Разработан `cli` (`main.c`)
5. Написаны 5 модульных тестов с использованием фреймворка `GTest` (проверка нулевых указателей, базовая вставка и алгоритм).
6. Реализован код `benchmark_graph.cpp` с применением фреймворка `Google Benchmark` для замера скорости алгоритма Прима и файлового ввода на графах разного размера (10, 50 и 150 вершин).
7. Подготовлен общий `Makefile`, который собирает исполняемые файлы проекта, тестов и бенчмарка.

- **CPU**: 16 x 2918 MHz
- **L3 Cache**: 24576 KiB
- **OS**: Windows (MSYS2 UCRT64)

## Запуск

Сборка и запуск основной программы (интерактивный режим) в каталоге `5_lab`:

```
mingw32-make run_main
```

Сборка и запуск модульных тестов GTest:

```
mingw32-make run_test
```

Сборка и запуск бенчмарков производительности Google Benchmark:

```
mingw32-make run_bench
```

Запуск основной программы с чтением из входного файла и записью минимального остовного дерева в выходной файл (без вызова интерактивного меню):

```
./main.exe target_input.txt target_output.txt
```
