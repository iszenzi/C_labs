# Лабораторная работа №3 (Преобразование арифметических выражений с применением деревьев)

## Цель работы
Составить программу на языке Си для выполнения заданных преобразований арифметических выражений с применением абстрактных синтаксических деревьев. Вариант задания: Редуцировать выражения, заменив операцию умножения переменной на целое число n на сумму n слагаемых: `a * 3 -> a + a + a`. Программа должна вводить и печатать выражения в исходном виде, преобразовывать их в деревья, выполнять заданные преобразования и печатать результаты в виде дерева и в текстовом представлении.
## Идея, метод, алгоритм решения задачи
- Выражение преобразуется в обратную польскую запись (ОПЗ) с помощью алгоритма сортировочной станции Дейкстры (Shunting-yard algorithm). Это обеспечивает правильную обработку приоритетов операций и скобок, а также поддержку унарных плюса и минуса.
- Полученная ОПЗ-строка преобразуется в абстрактное синтаксическое дерево (AST) с использованием стековой структуры.
- В дереве выполняется предварительное вычисление константных поддеревьев. Если подветка состоит только из чисел и операций, она вычисляется перед выполнением основной редукции (например `a * (2 * 2)` сначала станет `a * 4`).
- Редукция умножений: при нахождении узла умножения, где один потомок — переменная, а другой — целое число n, этот узел заменяется на поддерево сложений переменной n раз. При этом используется глубокое копирование узлов.
- Для вывода выражения в инфиксной форме реализован рекурсивный алгоритм с отслеживанием приоритетов родительских узлов.
- Если во всем дереве отсутствуют переменные, оно рекурсивно вычисляется и выводится результат.

## Сценарий выполнения работы
1. Описал объединение (union) и структуру узла абстрактного синтаксического дерева в `tree.h`.
2. Реализовал алгоритм Дейкстры для перевода выражения в обратную польскую запись с распознаванием унарных операторов.
3. Реализовал алгоритм построения дерева на основе обратной польской записи.
4. Добавил функции визуализации дерева с отступами и вывода инфиксной записи со снятием избыточных скобок.
5. Написал алгоритм редукции умножения переменной на число (с предварительной сверткой константных выражений).
6. Разработал CLI.
7. Создал `Makefile` со строгими правилами сборки (явное указание зависимостей без автоматических переменных).
8. Написал тестs с использованием `assert`

## Вывод
В ходе лабораторной работы разработана программа для преобразования арифметических выражений. Освоен и реализован алгоритм сортировочной станции Дейкстры для корректного разбора выражений с унарными операторами и приоритетами, а также алгоритм построения абстрактных синтаксических деревьев (AST). Выполнено заданное преобразование — редукция умножения переменной на число в арифметическую сумму. Для повышения качества программы реализована оптимизация свертки констант (Constant Folding) и интеллектуальный вывод без дублирующих скобок. Написаны модульные тесты для проверки корректности алгоритмов.
